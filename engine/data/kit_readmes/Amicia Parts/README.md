# Amicia Parts

**Purpose:** reference only. Import `amicia_parts.glb` to look at the game's original outfit: its 45 pieces in the main
chapters, as REF_<label>_<piece>, on the same YOUR_armature as the clean slate.

Do not export or edit these pieces. Model your own outfit in the clean slate (`Amicia Clean slate + weight body`): the
tool replaces the whole body, so none of these pieces stays in the game.
